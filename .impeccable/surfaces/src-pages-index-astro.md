# Home page

Scope: the whole first version of the site (home, install guide, what differs, blog, English page). Visitor mode: Persuade on the home page, Read on every other page.

Audience and job: a Linux user whose Vietnamese typing is broken arrives mid-frustration and needs three answers: what is this, will it work on my machine, how do I install it. Primary action: copy the one-line install command. Proof on hand: tested-level labels per distribution, measured results from the README, the project's own typing core running in the page.

Constraints: Vietnamese first with one English page; no screenshots, user counts, testimonials or support channel; internal names stay `lotus`; static output for GitHub Pages; the site goes live only after the first package release exists.

Memorable moment: the visitor types with their own keyboard and the keys on the page go down while Vietnamese appears on the sheet, composed by bamboo-core (the same core the input method uses) compiled to WebAssembly.

Unresolved: custom domain, pictorial logo.

## Direction contract

THESIS: The site is a keyboard at work. Keystrokes become Vietnamese in front of the visitor before any claim is made. It refuses the dark terminal-hero landing page with a feature-tile grid.

OWN-WORLD: An enamel green machine body owns the first viewport. Ivory keycaps carry condensed grotesque legends and a real pressed state. Anything typed sits on white paper sheets in a Didone-leaning typewriter mono. Carbon black ink. Ribbon red is reserved for the install action and struck marks. Tested levels are stamps whose outline form differs: solid, dashed, hollow.

STORY: The visitor sees typing work, checks their machine against stamps that name machine and date, then copies the install line.

FIRST VIEWPORT: Enamel field. A paper sheet rises from the top left across about sixty percent of the width with the wordmark "Ngó Sen" large, one sentence, and the line the demo types on. On the enamel to its right, the "Máy đã thử" stamps. Below the sheet, one full-width row of keycaps with a moving mark on the key being consumed. At the bottom, an ink-black strip holds the install command and a red copy key.

RAISES: provenance on every claim (from the memory quilt); a running mark that shows which key is now (from the step-row drum machine); state carried by form, not hue (from the emission-line rail); one action only gets the loudest colour (from the deco lobby).

FORM: grounded candidate 4 of 7 (keyboard), assigned by the roll and chosen by the user; seed key 5b08eff8; code-led.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
